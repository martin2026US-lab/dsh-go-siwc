## 已安装用户

可先切换到 DSH 的其他 Provider。需要移除本插件时，在插件面板退出登录，再在对应主机终端执行：

```sh
dsh plugin --profile web remove local-openai-siwc
```

随后重启引擎。移除插件通常保留本地数据，登录数据请通过面板中的退出登录及取消记住登录操作清理。

问题反馈：[Issues](https://github.com/martin2026US-lab/dsh-go-siwc/issues)。请妥善保管令牌与账户资料。
